# Near marketing website

Static marketing site for Near. `index.html` is the deployable root; its CSS, JavaScript, images and video use relative paths. A static host such as Vercel can serve this directory without a build command.

The site uses Near's share-page visual language: a blue night backdrop, warm ticket surfaces, Unbounded headlines and compact printed metadata. The illustrative event photography is credited in the footer and in `assets/events/SOURCES.md`.

## Search Console

Once this repository is deployed to `www.whatsnear.in`, submit:

`https://www.whatsnear.in/sitemap.xml`

`robots.txt` advertises the same URL. The sitemap lists the home page, Privacy Policy, Terms of Service, Community Guidelines and Account Deletion. The existing Privacy Policy, Community Guidelines and Account Deletion pages were copied verbatim from the published site on 27 October 2026; the site links to the canonical Privacy Policy URL.

Pushing this repository does not itself establish the domain or confirm a deployment. Verify the deployed sitemap responds with XML before submitting it to Google Search Console.
